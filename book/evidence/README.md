# 证据副本（仓外原件的入库留证）

本目录收的是**仓外原件的逐行副本**。

## 为什么收进来

书的规矩是「每条主张都要能被读者当场核」。前言与尾声里有一类主张——
「134 条未提交快照」这个数量和它的性质——原来的出处是
`mcopilot-pending-20261022/MANIFEST.txt`，那是发布前的工作区快照仓，**不随本仓公开**。
读者按坐标去查，会落到一个拿不到的仓里 → 主张就变成了**只有作者能核**的主张。

所以把原件收进来：**仓外原件不入仓，但被引用的那几件要留证**。

## 副本的规矩

| 规矩 | 为什么 |
|---|---|
| **逐行不变**（只做行内替换） | 书的坐标要能原样指到副本上。副本加一行表头，坐标就全错位一位——那样等于把"可核"改成了"看着像可核" |
| 只脱敏本机绝对路径 | 家目录/工作区路径是**这台机器的事实**，不是主张的一部分；换掉它不改变任何一个数字或判断 |
| 其余一字未改 | 副本一旦"顺手润色"，它就不再是证据了，只是转述 |
