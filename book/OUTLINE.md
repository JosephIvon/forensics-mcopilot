## 0. 三重定位（前言素材）

> 2026-10-24 更新：本书开源后面对的是**一类开发者**，不是一个人的求职。
> 下面第 1 条原来的定位是「求职展示件」——那是对**一个人的简历**的包装；
> 留下来的内核是「**可检查的证据系统**」，它对任何读者都成立，且更重要。

1. **可检查的证据系统**：书=每个主张绑可运行工件（书→仓库→台账验证链），
   读者按坐标当场复核；这一条对"开源码的读者"和"看简历的读者"同样成立。
2. **讲师课程原型**：取证式学习 = 体验式学习（百年老手艺）的成本坍缩版。
   抗质疑表述："项目成本人月→小时、反馈名师→LLM 无限供给、成书一年→一周、
   验证从无解→便宜但必须人做。我不是发明教学法，是第一次让个人能跑通全闭环。"
3. **数字程序员知识内核**（修正版）：不是攒量变向量库，是**结构化判据库+
   检索层+降级机制**。差异化来自私有过程知识（判据/锚点/坑谱），预训练里没有。

## 1. 生产纪律（全书有效，违反即返工）

- 方法论章**只编辑不创作**，每个事实性句子挂坐标（`文件:行` / `commit`，见 `ASSETS.md`）
- **引用规范**：事实性句子挂耐久工件坐标；过程叙事标"作者亲历"，不引用会话、
  不留会话快照——作者本人是叙事的证人，耐久工件是结论的证人
- **锚型分立**：版本库文件挂行锚（`文件:行`）；只追加的活文件（台账/记忆）挂
  节锚（`文件 §节名`）——活文件的行号会被追加冲走，行锚挂在活文件上等于
  预制的引用腐烂
- 陌生域推导章：**亲手验算后**才许落笔，章首标"已验算 YYYY-MM-DD"
- 每章代码工件**必须可运行**（门禁现跑即为演示）
- 开放题参考答案=**真实裁决记录，含代价**（这是对 hello-agents 形制的超越点）
- 语料条目元数据 schema（入库即带）：

```json
{
  "id": "R16",
  "claim": "一句话规则",
  "type": "A偏好|B流程|C领域|D元认知",
  "anchors": ["mcopilot:scripts/gate_negative.ps1", "session:2d09:L147"],
  "context": "适用上下文",
  "last_verified": "2026-10-22",
  "expiry": "失效条件",
  "status": "正式|候选|降级"
}
```

## 3. 裁剪输出（**一件**）

- **可验证主张**：每章末的「可验证主张」块——一句主张 + 锚点链接（当场可验）
- **讲师切分**：每章标注 90 分钟课的切分点（概念 20'/动手 40'/习题复盘 30'）

两段合成**一件**裁剪件 `crops/裁剪版.md`（2026-10-24 起）：早先按用途分成"简历版 / 讲师版"两件，
那是个人求职的用法；开源后面对的是**一类开发者**，他们要的是方法与证据，不是简历模板——
所以求职的挑法删掉，主张与切分都留着，合成一件。
