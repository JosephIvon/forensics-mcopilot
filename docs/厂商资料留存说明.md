# 厂商资料留存说明（磁盘清理的执行记录与依据）

> 时间：2026-10-20
> 触发：用户要求「归档的文件直接删，不要占磁盘空间」
> 原则：**「归档」指分析过程产生的重复件与临时件，不指厂商一手原件。**

---

## 0. 结论先说

`vendor_docs/` 从 **246.3 MB 清到 225.6 MB**（释放 20.7 MB），
另删掉 `_scratch/` 里的 12 个一次性分析脚本（23.9 KB）。

**但没有整目录删 `extract/`** —— 逐件按 SHA-256 核对后发现，
`extract/` 里 38 个文件中有 **24 个（25.8 MB）在别处没有同内容原件**，
其中包含 `dll_exports.csv`（PE 导出表真值）的**原始来源**。
整目录删掉 = 把真值的根拔了。

---

## 1. 逐件核对方法

对 `extract/` 下每个文件算 SHA-256，与 `extract/` 之外全部 169 个文件的哈希集合比对：

| 分类 | 件数 | 体积 | 处置 |
|---|---|---|---|
| 与别处**同内容**（纯重复） | 14 | 20.7 MB | **删** |
| **仅此一处**（一手原件） | 24 | 25.8 MB | **留** |
| `vendor_docs/_scratch/` | 12 | 23.9 KB | **删**（一次性分析脚本残留） |

## 2. 删掉的 14 个重复件（节选）

```
   3214.7 KB  extract\leisai_pkgs\DMC系列控制卡函数库\LTDMC2024-09-09-2464.zip
                    -> 同内容: DMC系列控制卡函数库\LTDMC2024-09-09-2464.zip
   1802.1 KB  extract\leisai_pkgs\DMC系列控制卡头文件\20241209头文件更新.zip
                    -> 同内容: DMC系列控制卡头文件\20241209头文件更新.zip
    ...（其余为 EMC 系列函数库 zip、EMC 开发头文件下的 LTDMC.cs/.vb/.bas/.h/.dll/.llb/.lvlib）
```

全部是「zip 原件已在别处，解包副本也在别处」的**三重复**。

## 3. 留下的 24 个一手原件 —— 为什么不能删

| 类别 | 件数 | 为什么是根 |
|---|---|---|
| **DLL 本体** | `zmotion.dll`(3.5 MB)、`zauxdll.dll`(2.3 MB)、`LTDMC.dll` 32/64 位共 5 份(12.6 MB) | **`dll_exports.csv`（PE 导出表真值）就是从这些 DLL 的 PE 导出表抽的**。删了就没法复核「这个符号到底导没导出」，也没法回答「`zauxdll.dll` 是不是只有 64 位」这类问题 |
| **导入库** | `LTDMC.lib` ×5、`zauxdll.lib`、`zmotion.lib` | 链接期符号名与调用约定的旁证 |
| **官方头文件** | `LTDMC.h` ×2（升级包 V2.5.7.23 / 20240624 版） | C 头文件是三层真值的第二层；两个版本可对照版本差异 |
| **官方 C# 绑定** | `LTDMC.cs` ×2（升级包 / 20240624 版） | 第四层真值（返回类型）的来源 |
| **其他官方件** | `LTDMC.vb`、`LTDMC.bas`、`LTDMC2.bas`、`README.doc`、`注意事项.txt` | 厂商随包文件；`.bas`/`.vb` 是 VB 侧绑定，交叉佐证 C# 绑定 |

> `LTDMC.cs` 的两个版本与 `EMC系列开发头文件\C#\LTDMC.cs`（本项目抽取时用的那一份）
> **内容不同**（升级包版本更全），所以三份都留。

## 4. 清理后仍能跑通的验证

- `scripts/extract_binding_returns.py` 重跑 → 与入库的 `binding_returns.csv` 完全一致
  （由 `tests/test_binding_truth.py::test_extractor_is_reproducible` 守住）
- `scripts/check_cam_capability.py` → 凸轮能力结论不变

## 5. 往后的规矩

1. **厂商原件只进不出**。`vendor_docs/` 是本项目唯一的外部一手来源。
2. **分析产物（CSV/JSON/脚本）一律放 `mcopilot/knowledge/` 与 `mcopilot/scripts/`，不放 vendor_docs**。
3. 厂商包里的 zip 原件可留一份，**解包副本不重复留**（按哈希核对后再删，不靠文件名猜）。
4. 一次性分析脚本用完即删，或收进 `mcopilot/scripts/` 变成可复现工具
   （本轮 `check_cam_capability.py` / `verify_crossval_claims.py` 就是这么收的）。
