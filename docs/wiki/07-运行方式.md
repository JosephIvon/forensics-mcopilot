## 1. 环境要求

| 项 | 要求 | 缺失后果 |
|---|---|---|
| **Python** | **3.9+**（`pyproject.toml:14`） | 必需 |
| 第三方库 | **无**（`dependencies = []`，`pyproject.toml:17`） | — |
| `matplotlib` | 可选，`pip install -e ".[charts]"` | 不画图但报告照出 |
| `pytest` | dev，`pip install -e ".[dev]"` | G6 门禁依赖 |
| **PowerShell 7（pwsh）** | 门禁必需 | ⚠ 5.1 下崩 `0x80131506` |
| .NET Framework `csc.exe` | G1-G4 必需 | 编译门 FAIL |
| com0com 虚拟串口对 | G4 建议 | G4 整门 SKIP |

## 2. 安装

**推荐：免安装**（`pythonpath=src` 已配 pytest，CLI 用 `PYTHONPATH`）：

```bat
set PYTHONPATH=src
python -m mcopilot all --out out
```

**或装成命令行工具**：

```bat
pip install -e .              :: 装出 mcopilot 命令
pip install -e ".[charts]"    :: 附带 matplotlib
pip install -e ".[dev]"       :: 附带 pytest
```

> **可编辑安装优先于 `pip install .`**：本仓的分发单元是**仓库**而不是 wheel——
> 真值基座 `knowledge/` 同时是运行时数据、被审证据与书的锚点，它指向仓外的厂商原件，
> 这层关系装不进一个 wheel。`pip install .` 装出来的 wheel 不含真值基座，
> 命令会报出一条**可照着做的错**（见 `core/util.py` 的 `_ROOT_HINT`）。

**或直接用仓库自带的 Windows 包装脚本**（[`mcopilot.bat`](../../mcopilot.bat)）：

```bat
mcopilot.bat all --out out
```

`mcopilot.bat` 的三个行为：设 `PYTHONIOENCODING=utf-8` →
解释器可用 `MCOPILOT_PYTHON` 环境变量覆盖（缺省 `python`）→
设 `PYTHONPATH=%MCOPILOT_DIR%src` 后 `python -m mcopilot %*`。
解释器找不到时**明确报错退出 1**，不静默降级。

## 4. CLI 全命令

```
mcopilot <域> <动作> [参数]      全局 --out（缺省 out/）
```

九个域：`requirements` / `motion` / `cam` / `forensics` / `spc` / `review` / `adapter` / `servo` / `all`。

### requirements —— 工业需求基线与工具覆盖审计
```bat
mcopilot requirements report [--out DIR] [--stem S]
```
产物 `requirements_map.md` / `.html` + 机器可读的 `knowledge/requirements_map.json`。

### motion —— 运动参数验证
```bat
mcopilot motion plan --distance 100 --v 200 --a 1000 --j 5000 [--freq 50] [--damping 0.7] [--tol 0.01]
mcopilot motion gear --lead 10 --encoder 131072 --ratio 1 --ppr 16384 --configured 1638.4 --travel 200
mcopilot motion compare --distance D --v V --a A --j J --target T --counts-per-mm C --exposure-us U [--max-shift 0.01]
mcopilot motion vectors [--file out/golden_vectors.json]
```
`motion gear` 不一致时返回 **2**。

### cam —— 电子凸轮
```bat
mcopilot cam check <table.csv> --master-v 360 --slave-v-max 300 --slave-a-max 2000
                     [--master-a 0] [--slave-travel N] [--freq F] [--tol T]
                     [--master-unit deg] [--slave-unit mm] [--stem S]
mcopilot cam plan --master-travel 360 --slave-travel 20 --segments 4
                  --master-v 360 --slave-v-max 300 --slave-a-max 2000
                  [--slave-ratios 1,2,1] [--ramp-points 4]
mcopilot cam caps
```
`cam check` 结论 `fail` 时返回 **2**。

### forensics —— 日志取证
```bat
mcopilot forensics analyze <log>            REM 根因分析
mcopilot forensics probe <log>              REM 格式体检：量化适配成本与哪些检测器跑不了
mcopilot forensics thresholds <log>         REM 阈值灵敏度：结论翻转点 + 检测器误报边界
```

### spc / review / adapter
```bat
mcopilot spc report <csv> --metric place_x_mm [--group-by lot] [--usl U] [--lsl L]
                                  [--result-col C] [--ng-col C]
mcopilot review <路径...> [--root R]       REM 有高危返回 1
mcopilot adapter gen --sdk dmc            REM ⚠ --out 指产物根，C# 统一落 out\csharp\
mcopilot adapter matrix
```

### servo —— 伺服诊断
```bat
mcopilot servo diagnose <wave.csv> [--accel 1000] [--time-unit auto|s|ms|us]
                        [--events events.jsonl] [--axis axis.json]
                        [--drive-params drive_params.json]
mcopilot servo synth [--model 2nd|2inertia] [--wn 60] [--zeta 0.4]
                     [--j1 1] [--j2 1] [--wf 300] [--zf 0.05]
                     [--kt 1] [--kp 400] [--kv 0] [--duration 0.6] [--fs 2000]
```

四个侧车参数（[`src/mcopilot/cli.py:503-516`](../../src/mcopilot/cli.py)）的说明值得原文引用：

- `--time-unit`：**判定错会导致 ωn 差 1000 倍**，默认按列名自动判定。
- `--events`：C6 格式事件流。**补上它才能评软件诱导族判据**（SRV-23/24/25/26/28/29）；
  事件与波形逐拍对齐（锚点残差 ≤ 时钟不确定度）才允许因果归因。
- `--axis`：轴铭牌侧车（cpr/pole_pairs/screw_pitch_mm）。有了它才能把转矩纹波谱线归因到阶次。
- `--drive-params`：驱动器参数侧车（`current_loop_bandwidth_hz` 必填）。有了它才能评 SRV-18。

### all
```bat
mcopilot all [--out DIR]
```

## 6. 门禁运行

```powershell
# 总门禁（⚠ 必须 pwsh 7）
pwsh -NoProfile -File scripts\gate_protocol.ps1
pwsh -NoProfile -File scripts\gate_protocol.ps1 -Only G2,G5
pwsh -NoProfile -File scripts\gate_protocol.ps1 -TimeoutSeconds 600 -PythonExe <py> -PyTestExe <py>

# 负向检测力证明（独立于总门禁）
pwsh -NoProfile -File scripts\gate_negative.ps1
pwsh -NoProfile -File scripts\gate_negative.ps1 -Keep          REM 保留沙盒现场

# 各门本体
pwsh -File scripts\gate_farm.ps1 [-SkipRtu]                    REM G11
pwsh -File scripts\gate_onboard.ps1 [-Only A|B|C] [-Keep]      REM G10
pwsh -File scripts\gate_corpus.ps1                             REM G12
pwsh -File scripts\gate_docsync.ps1 [-RepoRoot R]              REM G8
pwsh -File scripts\compile_check.ps1 [-OutDir out\csharp]      REM 运动域（5.1 下 skip）

# 锚点门（Python，不是 ps1）
python scripts\gate_anchors.py [--strict] [--list]             REM G7
```

**参数风格提示**：门禁族**没有 `-Force`**。只有：
`-Keep`（保留沙盒，`gate_negative` / `gate_onboard`）、
`-Only`（`gate_protocol` 是**门号逗号列表**；`gate_onboard` 是**场景单值**，两者语义不同）、
`-SkipRtu`（`gate_farm`）、`--strict`（`gate_anchors.py`）。

## 12. 五个必知的坑

| # | 坑 | 后果 | 对策 |
|---|---|---|---|
| 1 | **PowerShell 5.1 跑门禁** | `0x80131506` 崩溃 | 一律 `pwsh -NoProfile` |
| 2 | **C# 源码无 UTF-8 BOM** | 中文注释按 GBK 解码 → 一堆看不懂的语法错误 | `write_cs()` 强制 `utf-8-sig`；编译加 `/codepage:65001` |
| 3 | **协议域引用旧 `ModbusClients.dll`** | CS1061（缺 `TransactRaw()`） | 源码直编，不用 `/r:` |
| 4 | **`/r:` 参数带内嵌引号** | pwsh 7.3+ 转义 → 误报 `CS0006` | 不加引号（该路径无空格） |
| 5 | **COM ≥ 10 用 `open('COM4')`** | 串口打开失败 | 路径必须 `\\.\COM4` |

## 13. 边界声明（README §七，摘录）

1. **它不会替你调伺服。** 惯量辨识、增益整定、共振规避必须上机 + 示波器。
   它能做的是**离线波形诊断**（读波形 → 反推等效参数 → 候选根因），以及整定前的预算校验。
2. **估出来的是等效参数，不是物理真值** —— 跟随误差是**实测值**，不是估算（有编码器的轴上直接来自编码器计数 / 驱动器 `0x6064`）。
3. 剩余边界详见 [README §七](../../README.md)。
