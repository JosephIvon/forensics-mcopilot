## 二、✗ 更正一：cmd / fb 的「12–120 Hz 带内能量占比」数值不成立

### 报告原文（`交叉验证_Export10.md` §3 末表）

| 通道 | 报告的带内占比 | 报告的谱峰 |
|---|---|---|
| cmd | **65.71 %** | 100.1 / 99.6 / 200.2 / 199.7 Hz |
| fb | **3.77 %** | 0.49 / 0.98 / 1.46 / 1.95 Hz |
| err | 65.73 % | 100.1 / 99.6 / 200.2 / 199.7 Hz |

### 我的复算（斜坡窗口 t=10.077~12.124 s，nfft=2048）

| 通道 | 复算带内占比 | 复算带内主峰 |
|---|---|---|
| cmd | **2.21 %** | 12.2 / 12.7 / 13.2 / 13.7 Hz（低频泄漏裙边） |
| fb | **2.21 %** | 同上 |
| err | **63.75 %** | **100.1 / 99.6 Hz** ✅ |

> 其它窗口复算：静止尾段 t=16.60~18.65 s → cmd 2.13% / fb 2.15% / err 59.68%（峰 100.1 Hz）；
> 头部 t=0~2.05 s（cmd 恒定）→ cmd 0.00% / fb 6.89%。

**结论**：带内占比 63.75~65.7% 这个量级**只对 err 成立**。
cmd 与 fb 都在 **2% 量级**，不是 65.71% / 3.77%。
（err 占比高不是因为它「内容更多」，而是因为 err 的总动态量本身只有 ±0.34 mm，
分母极小——见下一节。）

## 三、✗ 更正二：「反馈通道里根本没有 100 Hz」是错的

### 报告原文（§3 末表下方 + §F-07）

> 「误差谱在怀疑带内的内容 100 % 是指令刷新率（100 Hz）及其谐波，**反馈通道里根本没有**。」
> 「fb 通道 12–120 Hz 能量占比 3.77 %，峰全在 0.49 / 0.98 / 1.46 / 1.95 Hz（斜坡本身），**没有 100 Hz**。」

### 我的复算：逐通道 100 Hz / 200 Hz 谱线幅值

DFT bin = 0.488281 Hz；100 Hz 落在 k=204.8 附近（bin 204 = 99.61 Hz），200 Hz 落在 k=409.6 附近（bin 409 = 199.71 Hz）。

**斜坡窗口 t=10.077~12.124 s**

| 通道 | 99.6 Hz 幅值 | 199.7 Hz 幅值 | 窗口 RMS | a100/RMS |
|---|---|---|---|---|
| cmd | 0.007776 | 0.004262 | 1.182475 | 0.66 % |
| **fb** | **0.006447** | 0.003353 | 1.182494 | 0.55 % |
| err | 0.001551 | 0.001708 | 0.007492 | **20.7 %** |

**静止尾段 t=16.60~18.65 s**：cmd 0.005726 / fb 0.006348 / err 0.000965，形态相同。

**结论**：**fb 里确实有 99.6 Hz 谱线**，幅值 0.0064 mm，甚至比 err 里的 0.0016 mm 还大。
原因是 cmd 是 100 Hz 刷新的阶梯，轴的反馈当然跟着这个阶梯走——
所以这条线在 cmd / fb / err 里**物理都真实存在**，不是「伪谱线」。

**报告把它叫「伪谱线」是定性错误。** 它是**真实成分**，只是：
- 幅值极小：err 里 0.001551 mm，相对 err 去偏置动态 std 0.270374 mm = **0.574 %**；
- 且它属于**指令侧**（对象响应里不产生这条线），不属于被控对象的动态。

（报告 §F-07 给的「幅值 0.00316 mm、相对 0.27 mm 动态误差只有 1.2%」——量级一致，
我的复算是 0.001551 mm / 0.574%，窗口不同有出入，不影响判断。）

## 四、更正后的判据结论（这才是对实现有约束力的部分）

报告的操作性结论**仍然成立**，但支撑它的理由要改写：

| | 报告的说法 | 更正后 |
|---|---|---|
| 100 Hz 线的性质 | 伪谱线（假的） | **真实成分**（指令刷新阶梯透传到轴），但幅值可忽略、且非对象响应 |
| 为什么误报风险是真的 | 「100 % 来自指令侧，反馈里没有」 | **带内能量占比 63.75% 会被误读，但绝对幅值只占动态误差 0.574%** |
| 误报机理 | 谱峰与刷新率重合 | **判据用「带内占比 / 相对突出度」这类无量纲量，被真实但微弱的刷新线带偏** |

### 因此频率类判据必须这样写

1. **以绝对幅值相对误差动态量级判定**，不得用带内能量占比、不得用相对突出度。
   建议：谱峰幅值 / 误差动态 std < 阈值（如 5%）时，该谱峰**不作为物理现象**，
   只作 `not_evaluable` 登记。
2. **指令刷新率是可直接测量的量**：从 cmd 通道跳变间隔中位数得出（本数据 10 ms → 100 Hz）。
   落在刷新率及其谐波上的谱峰，标为「指令刷新成分，非对象响应」，
   **不进 `hypotheses[]`**，进 `differential.not_evaluable`，
   `blocked_by` 写明「谱线与指令刷新率重合，非被控对象响应」。
3. 报告必须同时打印：**谱线绝对幅值**、**误差动态 std**、**两者比值**、**频率分辨率 fs/nfft**。
   **不得只打印「突出度」这种无量纲数字**——F-07 的「0.49 Hz / 突出度 238」就是这么误导人的。
4. 主频落在最低/最高 bin（k=1 即 fs/nfft）时必须提示。
5. 频谱窗口必须落在真正的稳态段；窗口跨运动事件 → 降级为不适用。

## 五、复现方式

本次复算脚本为一次性脚本（跑在会话工作区，未入库）。核心计算：

- 时基：`t_ms/1000`，`fs = (n-1)/(t[-1]-t[0])`
- 偏置分解：`mean = Σe/n`，`std = sqrt(Σ(e-mean)²/n)`，`动态占比 = std/max|e|`
- 跳变间隔：`[i for i in 1..n-1 if |cmd[i]-cmd[i-1]|>1e-9]`，相邻间隔取中位数
- 谱线幅值：单边幅值 `2·|DFT_k|/N`，去均值，nfft=2048，k=204（99.61 Hz）/ k=409（199.71 Hz）
- 带内占比：同一 DFT 的 12–120 Hz 功率和 / 全带功率和

> **不要用 `mcopilot.agents.servo` 的函数复算**——那正是被审对象。
