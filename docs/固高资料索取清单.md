## 三、缺的信息：**3 项必须 + 3 项建议**（一次问齐）

### 必须（拿到才能上真机）

**M1. 当量变换的确切公式** —— 当量是 `GT_ProfileScale(axis, alpha, beta)` / `GT_EncScale` 的分数比，
手册 p212 / p181 只给了取值范围 `(-32767,0)∪(0,32767)` 与「**alpha 的绝对值要大于 beta 的绝对值**」，
**没有给变换公式、也没说 alpha/beta 谁在分子**（官方 `gts.h` / `gts.cs` 里也只有函数声明，没有公式）。

- 要问：**轴位置 = 规划位置 × ? ，alpha 与 beta 谁在分子？**
- 为什么要问：搞反 → mm↔pulse 换算**整体偏一个未知比例，而且控制器不报错**。
- 我方当前做法（不猜）：**不下发**任何当量变换指令，要求控制器保持**默认 1:1 当量**
  （手册 p60 原文：「默认情况下，规划器位置的当量与轴的规划位置的当量之比是 1:1」），
  脉冲当量（脉冲/mm）由现场提供、在软件侧换算。
- 附带要问：**现场 MCT2008 配置里当量配的是多少？有没有被改过？**

**M2. 现场卡的准确型号 + 固件版本 + 端子板型号**

- 型号含义我们已经查到了（**不用问，列出结论请核对**）：
  主卡 `GTS-400-PX-PCIe-00`，**X=G = 脉冲量输出、X=V = 模拟量或脉冲量输出**；
  标准版 PV/PG（伺服控制周期 125us、无 PID+前馈滤波器），增强版 VT/GT（有 PID+速度前馈+加速度前馈、
  带龙门/5 轴/PSO 功能）。端子板另有型号：**GT2-400-ACC2-VB-G**（四轴开环，配 -PG 主卡）/
  **GT2-400-ACC2-VB-V**（四轴闭环，配 -PV 主卡），加 **-A** 后缀 = 带 12 位 AD 与非轴 DA；
  配套屏蔽电缆 `CN17-ACC3-T1-0680X1X2`（X1X2 = 03/10/15/30 → 0.3/1.0/1.5/3.0 m）。
- 要问：① 现场主卡的**完整型号**与**固件版本**；② 现场**端子板的完整型号**；
  ③ 现场装的是不是标准版（PV/PG）还是增强版（VT/GT）。
- 为什么卡住：增强版才有龙门/5 轴/PSO 功能；PV 与 PG 决定有没有模拟量轴输出（能不能用模拟量模式伺服）；
  端子板型号对不上就买不到货。

**M3. SDK 版本 ↔ 固件版本 + 目标进程位数**

- 要问：① 本次交付对应的 SDK 版本（`gts.dll` 的版本号怎么查）；② 目标进程 x86 / x64；
  ③ DLL 与固件的版本匹配关系；④ 32 位 `gts.dll` 与 64 位 `gts.dll` 的**导出符号是否完全一致**
  （我们实测一致：各 782 个，但请贵司确认这是设计如此）。
- 为什么卡住：位数不匹配现场表现是「程序一开就崩」。
- **调用约定不用问，已确认**：官方 `gts.h` 第 3 行 `#define GT_API extern "C" short __stdcall` → `__stdcall`。

### 建议（不急，但上机前要定）

**S1. HSIO 通道与「脉冲计数源」的配置口径**
位置比较输出只有 HSIO 两个通道（`GT_CompareData`），手册 p175-178 已定死：
位置是**相对调用时当前位置的偏移**、每边最多 4096 点、必须单调（违反返回 7）、
`source`（0 内部脉冲计数器 / 1 外部编码器）**必须与配置文件里的「脉冲计数源」一致**。
端子已查实：HSIO 在**端子板 CN14** 上，`HSIO_A±` = 比较输出通道 0、`HSIO_B±` = 通道 1（差分）。
要问：① 现场 HSIO_A / HSIO_B 分别接到了哪个设备（相机触发？激光？）；② 现场「脉冲计数源」配的是哪一边；
③ 比较输出要脉冲还是电平、脉宽多少。

**S2. 位置锁存的触发源与触发沿**
手册 p214-215 已定死：固高的锁存 = **编码器捕获**，捕获源只有 `CAPTURE_HOME 1` / `CAPTURE_INDEX 2` /
`CAPTURE_PROBE 3` / `CAPTURE_HSIO0 6` / `CAPTURE_HSIO1 7` —— **普通 DI 不能做捕获**。
端子已查实：**探针接 EXI0**（CN9-1 第 17 脚，手册标注「通用输入 / 探针输入」），
辅助编码器 CN12/CN13 手册明确「**辅编不能用以捕获功能**」→ EXI1~EXI15 都不能做捕获。
要问：① 现场锁存触发信号接在**哪个口**（HOME 几号 / EXI0 / HSIO 几号）？② 触发沿是上升还是下降
（`sense`：0 下降沿 / 1 上升沿）？③ 锁存后要不要立即回零到该位置。

**S3. 坐标系 ↔ 规划轴的映射与插补需求**
手册 p216 已给 `TCrdPrm` 的结构体与 `profile[8]` 规则，但**具体映射是站点配置**。
要问：① 现场要不要用插补（多轴同步走直线/圆弧）？② 要用的话，坐标系 1 的 X/Y/Z 各对应哪几个轴？
③ 合成速度与合成加速度上限？（`GT_LnXY` 的 `synVel` 单位是 **pulse/ms**，`GT_ArcXYC` 的 `circleDir` 0=顺时针 / 1=逆时针、半径正负决定 ≤180° 还是 >180°。）

## 五、我们的实现现状（供贵司核对，**不必回复**）

- GTS 单卡库已实现 34 条 P/Invoke，**逐条与官方 `gts.cs` 对过**：函数名、参数个数、参数类型、
  `ref`/`out` 修饰全部一致；3 个结构体（`TTrapPrm`/`TJogPrm`/`THomePrm`）的字段顺序与字节偏移
  与官方 C# 绑定逐字段一致；调用约定 `StdCall`。
- 通用输入/输出只映射 **MC_GPI / MC_GPO 的 1~16**；限位、原点、驱动报警、到位是**另外的 IO 类型**，
  不在通用位图里。
- 位置比较与位置锁存**只走 HSIO 两个通道**；**普通 DI 不能做捕获**（探针用 EXI0）。
- **当量变换不下发**（公式未公开），要求控制器保持默认 1:1 当量，脉冲当量由现场提供、软件侧换算。
- **坐标系插补暂不实现**（`TCrdPrm.profile[8]` 的映射是站点配置），调用时显式抛异常，不做近似。
